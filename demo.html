小程序端操作逻辑

👆 顾客视角（装扮流程）

  1. 首页实景探店 → 点「AI 场景装扮」
  2. 上传/拍院子照片 → 看 AI 场景识别结果
  3. 选花卉（可多选、定数量，看详情/养护难度）
  4. 描述需求：风格标签 + 预算滑块 + 位置
  5. 提交 → 多阶段生成 → 多套方案切换
  6. 拖动对比前后 → 调数量 → 加入购物车/下单

⚙️ 后台处理链路

上传照片 → 对象存储；后端调用 AI：

① 场景理解类型/光照/空间 ② 商品抠图花卉去底 ③ 图生图融合生成效果图

返回效果图 + 商品清单 → 前端展示下单。

🛠 开发方案（轻量落地）

前端：微信小程序（原生 / uni-app / Taro）
后端：微信云开发 或 FastAPI/Node
AI：即梦/豆包、通义万相、可图 Kolors；抠图 SAM
存储：OSS/COS；成本：单图几分～几毛
